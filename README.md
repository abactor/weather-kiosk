# Weather kiosk

Source of truth for the Toronto forecast panel. Edit this tree. `/opt/weather-kiosk` is only the running copy.

## Layout

| Path | Role |
| --- | --- |
| `/home/pi/dev/weather-kiosk` | Git repo. App code, tests, and this README. |
| `weather_kiosk/` | The program. |
| `weather-kiosk` | Launcher. Runs `python3 -m weather_kiosk`. |
| `tests/` | Tests and the saved city-page fixture. |
| `/opt/weather-kiosk` | Runtime copy. The panel starts the program from here. |
| `~/.config/weather-kiosk` | This machine's config and caches. Not in git. |
| `~/.config/labwc/weather-kiosk.sh` | Manual session script. Starts the runtime copy, then Chromium. |

The app code in this repo is real files. It is not symlinked to `/opt`. Linking it the other way would make the install the source of truth.

`__pycache__/` is bytecode from running the app on this Pi. It is not source. `.gitignore` keeps it out of git.

## Config

`~/.config/weather-kiosk/`

Manual. The app only reads these. Create them by hand.

- `calendar.url`, mode `600`. One private iCal URL. Or set `WEATHER_KIOSK_CALENDAR_URL`. If both are missing, the reminder line stays blank.
- `transit.conf`. Lines of `stop <code>` and `route <number>`. A route belongs to the stop above it. Comments start with `#`. If this file is missing or has no stop with a route, the panel shows no buses.

Auto-generated by the app. Do not edit these, and do not commit them.

- `reminder.json`. Last reminder for today. Used only when a later calendar fetch fails.
- `transit-board.json`. Last bus board. Reused for five minutes when the live feed fails.
- `surface-gtfs/`. Public TTC schedule download. Refreshed when it is older than 14 days. Large.

The hourly forecast stash is also automatic. It is written beside the HTML output, as `<output>.hourly.json`, not in the config folder.

## Deploy

On the Pi, from this repo, copy the runtime files into `/opt`. Leave config, caches, and the generated HTML where they are.

```sh
rsync -a --delete \
  --exclude '.git/' \
  --exclude '__pycache__/' \
  --exclude '*.pyc' \
  --exclude 'tests/' \
  --exclude 'pytest.ini' \
  --exclude 'README.md' \
  --exclude '.gitignore' \
  /home/pi/dev/weather-kiosk/ \
  /opt/weather-kiosk/
```

That copies `weather_kiosk/` and the `weather-kiosk` launcher. Tests stay in the repo.

Restart the process that was started from `/opt` (`python3 -m weather_kiosk --interval 60`) so it loads the new code. The labwc script is what starts that process and Chromium. Config under `~/.config/weather-kiosk` is not part of the deploy.
